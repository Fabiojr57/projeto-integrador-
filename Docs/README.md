# 🔐 Tela de Login Web

## 📌 Sobre o Projeto

Este é um projeto simples de sistema web com tela de **login** e **cadastro de usuário**, desenvolvido utilizando **HTML, CSS e JavaScript**.

O objetivo é demonstrar conceitos básicos de:

* Estruturação de páginas web
* Validação de formulários
* Interatividade com JavaScript

---

## 🚀 Funcionalidades

### 🔑 Login

* Validação de e-mail e senha
* Exibição de mensagem de sucesso ou erro
* Campos obrigatórios

### 📝 Cadastro

* Cadastro de novo usuário
* Validação de senha (mínimo de 6 caracteres)
* Feedback visual para o usuário
